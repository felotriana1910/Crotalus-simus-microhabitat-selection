# **Microhabitat Selection of the Mesoamerican Rattlesnake (*Crotalus simus*)**
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23337942.svg)](https://doi.org/10.5281/zenodo.23337942)

## Description

This code is associated with the paper “Microhabitat selection of the tropical rattlesnake *Crotalus simus* (Serpentes: Viperidae) at the southernmost extent of its distribution”, accepted for publication in Biotropica. Data can be access [here](https://data.mendeley.com/datasets/s94ccbvzyj/1).

During 2023 and 2024, we successfully tracked 11 individuals of the Mesoamerican Rattlesnake (*Crotalus simus*) using radiotelemetry in Nosara, Nicoya Peninsula, Costa Rica. At each relocation, we recorded the coordinates of the snake’s location, the type of substrate on which the snake was lying (leaf litter, bare ground, log, small stones, rock, or vegetation), the environmental temperature (°C) and relative humidity (%) next to the snake, the distance to the nearest large tree (m), the distance to the nearest small tree (m), the distance to the nearest fallen log (m), the distance to the nearest water body (m), canopy cover (%), and the number of understory structures.

Additionally, we measured 213 locations within the snakes’ home ranges that were not used by the animals (pseudoabsences), as a measure of habitat availability. Pseudoabsences were randomly generated in QGIS, and the same microhabitat variables were recorded at each of these locations.

## Requirements and Installation

This code requires R 4.4.2+
